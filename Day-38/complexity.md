# Time and Space Complexity

## Time Complexity: O(1) for push_front, push_back, pop_front, pop_back, front, back, size

## Space Complexity: O(n) where n is the maximum size of the deque

where:
- n = number of elements / nodes
- m = number of rows or second array size
- h = height of the tree
- k = heap size / window size
- b = number of bits
