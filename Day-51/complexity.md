# Complexity Analysis

## Time Complexity

**O(h)**

Where `h` is the height of the Binary Search Tree.

The algorithm follows only one path from the root toward the nodes `p` and `q`.

* **Balanced BST:** `O(log n)`
* **Skewed BST:** `O(n)`

## Space Complexity

**O(1)**

The solution is iterative and uses only a constant amount of extra memory. No recursion or additional data structure is used.

## Summary

| Complexity | Value  |
| ---------- | ------ |
| Time       | `O(h)` |
| Space      | `O(1)` |

Where `h` is the height of the BST.
